Your project roadmap

A practical path from commit to container.

Follow the stages in order. Validate each stage before moving to the next one.

01

Version

Create a Git repository and push your code to GitHub.

02

Build

Create a responsive HTML and CSS website.

03

Containerize

Use Docker and Nginx to run the site locally.

04

Automate

Use a Jenkins pipeline to repeat build steps.

05

Orchestrate

Deploy replicas and expose the app with Kubernetes.

Quick Preview / Dockerfile
# Start with a small Nginx image
FROM nginx:alpine

# Copy the website into Nginx
COPY index.html /usr/share/nginx/html/index.html

# Document the web port
EXPOSE 80

# Build and run your image locally
# docker build -t devops-site .
# docker run -p 8085:80 devops-site
